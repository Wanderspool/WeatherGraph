    Glossary of Terms

    This glossary defines key meteorological, graph neural network (GNN), and performance-computing terms used throughout the WeatherGraph framework.

    Meteorology & Climate Science

    Analysis State

    The initial spatial representation of the state of the atmosphere at a specific moment in time ($t=0$). It is generated by combining historical observations with numerical weather prediction models through data assimilation.

    Autoregressive Rollout

    A multi-step forecasting process where the model's predictions for step $t+1$ are fed back into the model as input to generate the forecast for step $t+2$, repeating for the requested forecast horizon.

    Climate and Forecast (CF) Conventions

    A standard metadata schema for netCDF and Zarr files designed to promote the processing and sharing of atmospheric, oceanographic, and climate datasets. It requires standardized names, units, and coordinates.

    Copernicus Climate Data Store (CDS)

    The centralized data access portal of the Copernicus Climate Change Service (C3S), hosting global climate reanalysis datasets (such as ERA5) and seasonal forecasts.

    ERA5 Reanalysis

    The fifth-generation global atmospheric reanalysis dataset produced by the European Centre for Medium-Range Weather Forecasts (ECMWF), spanning from 1940 to the present. It combines physical model simulations with global observations to provide hourly estimates of atmospheric variables.

    Geopotential ($z$)

    The potential energy per unit mass of a body at a given elevation, relative to mean sea level ($m^2/s^2$). In meteorological models, it is used instead of geometric height because gravity varies across the earth's surface.

    Geopotential Height (gpm)

    An approximation of geometric height above mean sea level, calculated by dividing the geopotential by the standard gravity constant ($g = 9.80665\text{ m/s}^2$). It is measured in geopotential meters.

    GRIB2 Format

    General Regularly-distributed Information in Binary form (version 2). A standard binary data format defined by the World Meteorological Organization (WMO) for representing gridded meteorological field data.

    Specific Humidity ($q$)

    The ratio of the mass of water vapor to the total mass of the moist air parcel ($kg/kg$). Unlike relative humidity, specific humidity is conserved during vertical transport.

    Wind Velocity Components ($u, v, w$)

    Decomposed components of the 3D wind velocity vector: * $u$: The eastward wind component (zonal velocity). * $v$: The northward wind component (meridional velocity). * $w$: The vertical wind component, typically expressed as vertical pressure velocity ($Pa/s$).

    Machine Learning & Graph Neural Networks (GNN)

    Autoregressive Drift

    The gradual accumulation of small prediction errors over successive steps of an autoregressive rollout, which can cause GNN output variables to drift away from physical atmospheric states after long time horizons.

    Gated Recurrent Unit (GRU) Graph Cell

    A recurrent neural network structure embedded within GNN message-passing nodes or edges. It allows the model to maintain and update a hidden temporal state across rollout iterations, improving forecast trajectory consistency.

    Graph Adjacency List

    A representation of a graph listing every edge connection as sender and receiver node pairs. WeatherGraph loads this layout from senders.npy and receivers.npy files to define the global grid connectivity.

    Halo Zone (Overlaps)

    The surrounding boundary region of grid cells added around a spatial partition (tile). The halo contains input coordinates from neighboring partitions required to compute predictions for the partition's owned nodes.

    Message-Passing GNN

    A Graph Neural Network architecture where node features are iteratively updated by aggregating message vectors sent from adjacent nodes along edges.

    Message-Passing Hops

    The number of times node features are aggregated and passed to neighbor nodes in a GNN layer. The number of hops determines the spatial receptive field of each node.

    Spatial Partition Manifest

    A configuration file (usually in JSON format) that describes tile boundaries, edge connections, internal coordinate mappings, and blending weight paths for a spatially tiled model.

    Spatial Tiling

    A decomposition strategy where a global graph mesh is split into smaller, overlapping regional subgraphs. This allows models to run on resource-constrained systems without exceeding memory limits.

    Tile Bundle

    A directory or packaged bundle containing partitioned GNN model weights (ONNX), mesh subgraphs, and boundary index mappings generated by spatial tiling.

    Performance & Scientific Computing

    CPU Memory Arena

    ONNX Runtime's memory allocation system. It pre-allocates chunks of virtual memory to avoid the overhead of frequent malloc/free system calls. Disabling it releases memory back to the OS immediately at a slight speed cost.

    Execution Provider (EP)

    ONNX Runtime's abstraction layer for hardware accelerators. EPs map ONNX nodes to hardware-specific backends (e.g. CUDA/TensorRT for NVIDIA, ROCm for AMD, OpenVINO for Intel).

    Memory Mapping (memmap)

    A system call that maps files directly into a process's address space. WeatherGraph uses memory mapping to offload large tile buffers to disk, leveraging the operating system's page cache.

    OpenVINO Execution Provider

    An ONNX Runtime backend optimized by Intel for running deep learning models on Intel CPUs and GPUs.

    pybind11

    A lightweight header-only C++ library that exposes C++ types and memory buffers in Python, enabling high-performance zero-copy bindings.

    TensorRT Execution Provider

    An ONNX Runtime backend utilizing NVIDIA's TensorRT optimizer to compile and execute ONNX graphs directly on CUDA-enabled GPUs with optimal layer fusion.

    Welford's Algorithm

    An $O(1)$-memory algorithm for calculating the running mean and sample variance of a sequence in a single pass. WeatherGraph uses Welford's algorithm to compute ensemble spread in real-time.

    Zero-Copy Boundary

    A software design that passes memory buffer pointers directly between execution environments (like Python and C++) without copying data, eliminating CPU/GPU memory latency.
